# Security Policy

## Reporting a vulnerability

Please do not disclose exploitable vulnerabilities in a public issue. Use GitHub's private vulnerability reporting feature for this repository.

Include affected versions, reproduction steps, impact, and any suggested mitigation. Avoid attaching personal photos or videos; create a minimal synthetic fixture instead.

## Security posture

LiveForge is designed for local media processing. The conversion pipeline must not upload media, analytics, thumbnails, or metadata without a separate, explicit, opt-in design decision.
